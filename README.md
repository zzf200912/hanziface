# Mandarin Hub — Learn Chinese through shows, games and HSK exams

**Official website: https://hanziface.com**

Mandarin Hub helps English speakers learn Mandarin Chinese through the TV shows, movies and games they already love — combined with a structured HSK-aligned curriculum, mock exams and spaced-repetition vocabulary review.

## What's inside

- **26 free lessons** across 3 levels, each with dialogue → vocabulary → quiz → speaking practice → certificate
- **HSK 1–3 mock exams** with instant feedback and score tracking
- **Spaced-repetition (SRS) vocabulary** reviewer based on the Leitner system
- **Culture-based content** — Nezha, Genshin Impact, Chinese dramas
- **Text-to-speech and speech recognition** for pronunciation practice
